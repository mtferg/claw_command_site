Grouping

Every project is a planet.

Repos become planets, and worktrees fly under their own flag as repo ⎇ branch. Robots orbit the project they belong to, so one glance tells you what each crew of agents is up to. Drag a robot to another planet to regroup it. Drop one in open space and it gets a planet of its own. Drag one into the black hole to archive it, and yes, it asks first.

Alerting

Amber means you.

Motion is spent on exactly one job: showing which robot needs a human. A waving robot is the only big, fast thing in a field of small, slow ones. In the app, 68% of all on-screen motion belongs to the agents waiting on you. Errors smoke quietly, sleepers snooze, and the fleet stays calm enough to live on a second monitor all day. Press N and the camera flies to whoever has waited longest.

Triage

A map for the feel. A list for the work.

The command deck is the same fleet, the boring way. Grouped by state with needs input pinned to the top, sortable by waiting time, cost, or title, filterable by text, chassis, and planet. A full triage pass never has to touch the map. Each row shows what the robot is stuck on, how long it has waited, and what it has cost so far.

The wait clock turns amber past thirty seconds, because half a minute of a human bottleneck is long enough to notice.

FAQ

Questions, answered.

What is Claw Command?
A macOS desktop app that shows every Claude Code session on your machine as a robot orbiting its project's planet. It is a live fleet view for agent orchestration: grouping by project, amber alerts when an agent needs input, and full keyboard control.
Is it a game?
It plays like one. Pixel robots, hand-painted planets, a black hole for the archive. But the fleet is real: every robot is one of your live Claude Code sessions, and the amber ones really do need you.
Does it work with my existing Claude Code sessions?
Yes. It reads the session transcripts Claude Code already writes to ~/.claude. Sessions from the last 24 hours appear automatically, grouped by project, with worktrees shown as repo ⎇ branch. No setup beyond installing the app.
Does it need an API key or an account?
No. There is no login, no API key, and no server. Claw Command runs as a single local process and your data stays on your machine.
Can it control my agents?
It orchestrates around them. You can jump into any session in the Claude app, regroup robots between planets, and archive the finished ones. It never types into your sessions and never edits your code.
