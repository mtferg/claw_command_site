Privacy Policy

Effective August 23, 2026 · Terms of Service

The short version

Claw Command runs entirely on your Mac. It has no accounts, no analytics, no tracking, and no server of ours that ever sees your data. Your Claude Code sessions — the code, prompts, and transcripts in them — never leave your machine.

What the app reads and writes

The app reads the session files Claude Code already writes to ~/.claude on your machine (or another folder you point it at), so it can draw your fleet. That reading happens locally, inside one process on your Mac. Nothing from those files — no transcripts, no file paths, no project names, no token counts — is ever transmitted anywhere.

The app writes one thing: its own local settings file (your planet layout, archived robots, and preferences). It never modifies your Claude Code data or your code.

The one network request the app makes

Once a day, the app checks for updates by fetching a small version file from clawcommand.space. That request carries no account, no identifier, and nothing about your sessions — it is an ordinary HTTPS request for a static file. Like any web request, the server host (GitHub Pages) can see your IP address in its standard logs; see GitHub's privacy statement. That is the app's only network activity.

This website

This site is static and served by GitHub Pages. We run no analytics and set no cookies. The site loads one font from Google Fonts, which means your browser makes a request to Google's servers; see Google's privacy policy.

Purchases

Payments are handled by our payment processor, [PAYMENT PROCESSOR], who acts as the merchant of record. They collect what a checkout needs (email, payment details) under their own privacy policy; we never see your payment details. We receive your email address only as part of the order record, and use it only for the purchase itself — the download link, receipts, and refunds. No marketing email unless you opt in.

Your data

Because the app collects nothing, there is nothing for us to export, correct, or delete — everything it knows lives in files on your machine, and deleting the app's local settings file removes all of it. For order records, contact us or the payment processor.

Changes

If this policy changes — for instance, if a future version adds an opt-in feature that talks to a server — we will update this page and note the change in the release notes of the version that introduces it.
